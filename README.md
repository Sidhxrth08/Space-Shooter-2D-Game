# 🚀 Space Shooter 2D Game

A 2D space shooter game where you control a spaceship, destroy incoming enemies, collect power-ups, and try to achieve the highest score.

---

## 🎮 Play the Game

**Play Space Shooter 2D Game:**  
https://sidhxrth08.github.io/Space-Shooter-2D-Game/Game%20Code.html

The game can be played directly in a web browser on a **Laptop/PC**.

**No installation required.**

---

## ✨ Features

- 🚀 Player-controlled spaceship
- 👾 Multiple types of enemies
- 🔫 Shooting and bullet mechanics
- 💥 Collision detection
- ❤️ Lives system
- 🏆 Score system
- ⚡ Power-ups
- 🎯 Increasing difficulty
- 🎬 Game animations
- 🔄 Game restart system
- 🎮 Keyboard and mouse controls

---

## 🎮 Game Controls

### 🚀 Start Game
🖱️ **Left Click** or **P** → Start the game

### 🛸 Movement
⬅️ **Left Click** or **Left Arrow (←)** → Move the spaceship left

➡️ **Right Click** or **Right Arrow (→)** → Move the spaceship right

### 🔫 Shooting
💥 **Spacebar** → Fire bullets

---

## 🏆 Objective

🎯 Destroy incoming enemies, survive as long as possible, collect power-ups, and achieve the highest score!
